SH3 Enhanced is a project that makes the PC version of Silent Hill 3 run properly on modern systems, with widescreen, 60 FPS, controller support, and fixes for long-standing bugs.

What the patch does

Graphics

  • ✓Widescreen Fix: Fixes FOV and aspect ratio for modern displays.
  • ✓Custom Resolutions: Sets output size and internal render-target size separately.
  • ✓Remove Black Bars: Removes the side bars during gameplay.
  • ✓Remove Cutscene Borders: Removes borders from in-engine cutscenes.
  • ✓Fullscreen Pause Menu: Expands the pause menu to widescreen.
  • ✓FMV Fix: Shows videos at 4:3 or crops them to fill widescreen. 16:9 video sources also work.
  • ✓DoF Resolution: Sets the target resolution for depth of field and otherworld corrosion.
  • ✓Shadow Resolution: Sets the dynamic shadow-map resolution.
  • ✓Status Screen Resolution: Raises the status-screen image resolution.
  • ✓Anisotropic Texture Filtering: Uses the highest anisotropy level your device supports.
  • ✓Fog Control: Adjusts fog detail with a configurable coefficient.
  • ✓Experimental Pause-Menu Geometry: Adjusts the horizontal bounds of one pause-menu quad. It does not increase texture resolution, and a translucent rectangle may appear in the Status preview.
  • ✓MSAA / DoF Compatibility: Blocks MSAA requests that can corrupt depth of field. FXAA is not included.

Content / Text

  • ✓"Wish House" Fix: Changes "Hope House" to "Wish House" in English text.
  • ✓Typo Fixes: Fixes the subway ladder message, apartment save-point text, apartment entrance sign, and a hospital memo.
  • ✓Missing Sewer Text: Restores Heather's missing English comments at the sewer wine rack.
  • ✓Unlock SH2 Easter Eggs: Unlocks four Silent Hill 2 save-data references without needing a cleared SH2 save.
  • ✓PS2-exclusive Media Outlet Costumes: Adds fourteen magazine shirts to the PC version. Enter a password in Extra Costume, then equip the shirt from Items.

Performance / Framerate

  • ✓60 FPS Timing: Keeps game timing stable at 60 FPS.
  • ✓Frame-Rate Modes: Choose 30 FPS, 60 FPS, or unlocked timing.
  • ✓Mirror Room Fix: In 60 FPS mode, caps the hospital storeroom at 30 FPS and returns to 60 FPS when you leave.

System / Stability

  • ✓Registry Redirect: Redirects SH3's install-path registry reads from HKLM to HKCU and points per-user paths to the folder the game is running from.
  • ✓Safe Mode Disable: Stops Safe Mode from resetting graphics settings after an abnormal exit.
  • ✓Options Menu Freeze Fix: Fixes a hang when opening the Options menu.
  • ✓CPU Affinity: Optionally sets which logical processors the game can use.
  • ✓Windowed / Borderless Mode: Runs the game in a resizable window or borderless fullscreen.
  • ✓White Border Fix: Removes the bright window-edge effect on Windows 10/11.
  • ✓Exception Handler: Writes a timestamped minidump after an unhandled crash.

Audio

  • ✓Muted Audio Recovery: Clears a Windows audio-session mute left over when the game starts.
  • ✓Audio Enhancement Pack: Loads the Silent Hill 3 Audio Enhancement Pack's AFS audio replacements without Reloaded II. The pack must be installed separately.

Tools / Presence

  • ✓Discord Rich Presence: Shows the current area and Heather's health when available.
  • ✓Configuration Tool: Edits patch settings and can save them beside the game executable you select.

Controls / UI

  • ✓XInput Controller Support: The bundled 32-bit Xidi bridge lets the game's DirectInput 8 input path work with XInput controllers.
  • ✓Controller Button Prompts: Choose Generic, Xbox, PlayStation, or Nintendo prompts.

Planned

  • Title and splash art: Upscale the main-menu image and other splash art, with a reversible way to install the replacements.
  • Inventory art: Identify the inventory background and check whether the item images can be improved.
  • Custom picture replacements: Support replacement images without changing the original game files.
  • FMV enhancement: Look into enhancing or replacing SH3's FMVs, inspired by the FMV Enhancement Pack in Silent Hill 2: Enhanced Edition.
  • Achievements: Add an achievement system based on the Silent Hill HD Collection achievement list.
  • Audio restoration: Look into missing dialogue, optional beta sounds, and audio sync problems.

Get the patch

Download the latest release ZIP and extract it into your Silent Hill 3 game folder, beside sh3.exe.

Download SH3 Enhanced
1

Install Silent Hill 3 for Windows

You need the original PC game installed first. SH3 Enhanced is a patch; it does not include the game or its files.

2

Extract the release ZIP

Extract the files into the folder containing sh3.exe. Merge folders if Windows asks.

3

Configure the patch

Open the Configuration Tool to change settings, then launch the game.

Compatibility

  • Requires the original Windows PC version of Silent Hill 3. The game is not included.
  • Supports the 32-bit PC executable with CRC32 372AE792.
  • Built for Windows 10 and Windows 11. Exclusively tested in Windows 11.

Troubleshooting

Confirm that the release files were extracted into the folder containing sh3.exe. The supported 32-bit PC executable has CRC32 372AE792. If the plugin still does not load, include SH3Enhanced.log when reporting the issue.

In a build that includes the font pack, make sure the files are installed under SH3 Enhanced Data\Fonts and set FontScale=4 in SH3Enhanced.ini. Set FontScale=0 to use the original game font. Restart the game after changing the setting.

In a build that includes the costume models, enter a shirt's case-sensitive password from the Extra Costume option on the main menu. Start an Extra New Game, then equip the unlocked shirt from Items. The passwords and previews are listed here.

Download SH3 Enhanced only from the project's official GitHub Releases page. If Windows Security flags a file, note the detection name and report it in a GitHub issue.

Edit SH3Enhanced.ini beside sh3.exe and set both ResolutionX and ResolutionY. Set both to 0 to use your desktop size. Restart the game after changing the file.

ResolutionX and ResolutionY control the display size. RenderResolutionX and RenderResolutionY set the game's internal render size. Leave the render values at 0 unless you specifically want to override the game's choice. Always set width and height together.

Set FullscreenPauseMenu=true in SH3Enhanced.ini to expand the pause menu to widescreen. This setting is enabled by default.

FMVWidescreenMode=0 keeps the original 4:3 framing. Set it to 1 to crop the video to fill a widescreen display, or 2 when using 16:9 video sources.

The project includes an Options menu freeze fix. Check SH3Enhanced.log beside sh3.exe for an Options warning; if the fix still doesn't work, attach the log to a GitHub issue.

60 FPS is the default mode. You can also select 30 FPS or unlocked timing in the Configuration Tool or SH3Enhanced.ini.

Open an issue on GitHub. Include what happened, what you expected, your game executable version, and SH3Enhanced.log if available.
