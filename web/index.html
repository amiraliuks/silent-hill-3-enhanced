A runtime patch for the original Windows PC release of Silent Hill 3, adding widescreen, resolution, frame-rate, and stability fixes.

Features

✓ implemented ○ planned

Graphics

  • ✓Widescreen Fix: Corrects FOV and aspect ratio for modern displays.
  • ✓Custom Resolution: Sets output and internal render resolutions in SH3Enhanced.ini.
  • ✓Remove Black Bars: Removes the gameplay side bars.
  • ✓Remove Cutscene Borders: Removes borders added during in-engine cutscenes.
  • ✓4:3 2D Elements: Keeps supported menus and interface elements at 4:3 on widescreen displays.
  • ○Fullscreen Pause Menu: Stretches the pause menu to fill the screen.
  • ✓FMV Fix: Displays videos at 4:3 or crops them to fill widescreen; also supports 16:9 video sources.
  • ○DoF Resolution: Increases depth-of-field render resolution.
  • ○Shadow Resolution: Increases shadow-map resolution.
  • ○Inventory Resolution: Increases inventory background resolution.
  • ○Status Screen Resolution: Increases status-screen resolution.
  • ○Anisotropic Texture Filtering: Enables the highest supported AF level.
  • ○Fog Control: Adjusts fog complexity.
  • ○Motion Trail Fix: Corrects dark trails caused by bloom on light sources.
  • ○Animated Wall Texture Fix: Corrects animated textures when using d3d8to9.

Audio

  • ○Restore Missing Dialogue: Restores dialogue audio removed from the PC release.
  • ✘Restore Beta Sounds: Optionally restores cut beta sound effects.
  • ○Audio Pulse Fix: Replaces PulseEvent audio synchronization.
  • ○Muted Audio Fix: Corrects audio muting after crashes during the TV or Lisa scene.

Performance / Framerate

  • ✓60 FPS Mode: Stable 60 FPS timing; confirmed in-game.
  • ✓Multiple FPS Modes: Supports 30 FPS, 60 FPS, and unlocked modes; 30 FPS and unlocked modes still need broader gameplay checks.
  • ○Mirror Room Fix: Forces 30 FPS in the hospital storeroom where effects require it.
  • ○MSAA / DoF Fix: Disables MSAA that corrupts depth of field and recommends FXAA.

System / Stability

  • ✓Registry Redirect: Redirects SH3 install-path reads from HKLM to HKCU and fills missing paths per-user.
  • ✓Safe Mode Disable: Prevents the game from reverting graphics settings after an abnormal exit.
  • ✓Options Menu Freeze Fix: Fixes the game hanging in the Options menu.
  • ○CPU Affinity Fix: Configures CPU core affinity to reduce frame-rate fluctuation.
  • ○Windowed / Borderless Mode: Runs the game in a window or borderless fullscreen.
  • ○White Border Fix: Corrects white borders on Windows 10/11.
  • ○d3d8to9: Converts DirectX 8 to DirectX 9 for compatibility and performance.
  • ○Exception Handler: Writes minidump files after a crash.

Content / Text

  • ✓“Wish House” Fix: Changes English instances of “Hope House” to “Wish House”.
  • ✓Typo Fixes: Corrects typos in the subway, apartments, and hospital.
  • ✓Missing Sewer Text: Restores untranslated text in the sewer level.
  • ✓Unlock SH2 Easter Eggs: Unlocks Silent Hill 2 references without completing the game.

Troubleshooting

Common fixes for the Windows PC version.

Once a release is available, extract every file beside sh3.exe. The supported PC executable has CRC32 372AE792. If it still won't load, include SH3Enhanced.log when reporting the issue.

Edit SH3Enhanced.ini beside sh3.exe and set both ResolutionX and ResolutionY. Set both to 0 to use your desktop size. Restart the game after changing the file.

ResolutionX and ResolutionY control the display size. RenderResolutionX and RenderResolutionY set the game's internal render size. Leave the render values at 0 unless you specifically want to override the game's choice. Always set width and height together.

By default, supported 2D elements stay arranged in a 4:3 area while gameplay uses the wider screen. Set Keep2DElementsAt4x3=false in SH3Enhanced.ini if you want to disable that behavior, then restart the game.

FMVWidescreenMode=0 keeps the original 4:3 framing. Set it to 1 to crop the video to fill a widescreen display, or 2 when using 16:9 video sources.

The project includes an Options menu freeze fix. Check SH3Enhanced.log beside sh3.exe for an Options warning; if the fix still doesn't work, attach the log to a GitHub issue.

60 FPS is the default and has been confirmed in-game. 30 FPS and unlocked timing modes are available, but still need broader gameplay checks.

Open an issue on GitHub. Include what happened, what you expected, your game executable version, and SH3Enhanced.log if available.
