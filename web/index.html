SH3 Enhanced is a project that makes the PC version of Silent Hill 3 run properly on modern systems, with widescreen, 60 FPS, controller support, and fixes for long-standing bugs.

What the patch does

Graphics

  • ✓Widescreen Fix: Corrects FOV and aspect ratio for modern displays.
  • ✓Custom Resolutions: Sets the output size and internal render-target size independently.
  • ✓Remove Black Bars: Removes the gameplay side bars.
  • ✓Remove Cutscene Borders: Removes borders added during in-engine cutscenes.
  • ✓Fullscreen Pause Menu: Expands the pause menu to widescreen.
  • ✓FMV Fix: Displays videos at 4:3 or crops them to fill widescreen; also supports 16:9 video sources.
  • ✓DoF Resolution: Sets the depth-of-field and otherworld-corrosion target resolution.
  • ✓Shadow Resolution: Sets the dynamic shadow-map resolution.
  • ✓Status Screen Resolution: Increases the status-screen image resolution.
  • ✓Anisotropic Texture Filtering: Uses the highest anisotropy level supported by the device.
  • ✓Fog Control: Adjusts fog detail with a configurable coefficient.
  • ✓Experimental Pause-Menu Geometry: Adjusts one pause-menu quad's horizontal bounds. It does not increase texture resolution and may show a translucent rectangle in the Status preview.
  • ✓MSAA / DoF Compatibility: Stops multisample anti-aliasing requests that can corrupt depth of field. FXAA is not included.

Content / Text

  • ✓"Wish House" Fix: Changes English instances of "Hope House" to "Wish House".
  • ✓Typo Fixes: Corrects the subway ladder message, the apartment save-point text, the apartment entrance sign, and a hospital memo.
  • ✓Missing Sewer Text: Restores Heather's missing English comments at the sewer wine rack.
  • ✓Unlock SH2 Easter Eggs: Unlocks four Silent Hill 2 save-data references without a cleared SH2 save.

Performance / Framerate

  • ✓60 FPS Timing: Provides stable game timing at 60 FPS.
  • ✓Frame-Rate Modes: Lets you choose 30 FPS, 60 FPS, or unlocked timing.
  • ✓Mirror Room Fix: In 60 FPS mode, caps the hospital storeroom at 30 FPS and restores 60 FPS when you leave.

System / Stability

  • ✓Registry Redirect: Redirects SH3's install-path reads from HKLM to HKCU and points the per-user paths to the folder containing the running game.
  • ✓Safe Mode Disable: Stops SH3's safe mode from resetting graphics settings after an abnormal exit.
  • ✓Options Menu Freeze Fix: Fixes a hang when opening the Options menu.
  • ✓CPU Affinity: Optionally selects logical processors for the game process.
  • ✓Windowed / Borderless Mode: Runs the game in a resizable window or borderless fullscreen.
  • ✓White Border Fix: Removes the bright extended window edge on Windows 10/11.
  • ✓Exception Handler: Writes a timestamped minidump after an unhandled crash.

Audio

  • ✓Muted Audio Recovery: Clears a persisted Windows audio-session mute when the game starts.

Tools / Presence

  • ✓Discord Rich Presence: Shows the current area and Heather's health when available.
  • ✓Configuration Tool: Edits patch settings and can save them beside the selected game executable.

Controls / UI

  • ✓XInput Controller Support: The bundled 32-bit Xidi bridge lets the game's DirectInput 8 input path use XInput controllers.
  • ✓Controller Button Prompts: Offers Generic, Xbox, PlayStation, or Nintendo prompt styles.

Planned

  • →Title and splash artwork: Upscale the main-menu image and related splash art, with a reversible way to install the replacements.
  • →Inventory artwork: Identify the inventory backdrop and assess the existing item images for possible improvements.
  • →Custom picture replacements: Support replacement images without modifying the original game files.
  • →Achievements: Implement Achievement system, using the achievements of Silent Hill HD Collection.
  • →Audio Enhancement Pack support: Find way to use the Silent Hill 3 Audio Enhancement Pack without installing Reloaded II.
  • →Audio restoration: Investigate missing dialogue, optional beta sounds, and audio synchronization issues.

Troubleshooting

Once a release is available, extract every file beside sh3.exe. The supported PC executable has CRC32 372AE792. If it still won't load, include SH3Enhanced.log when reporting the issue.

Edit SH3Enhanced.ini beside sh3.exe and set both ResolutionX and ResolutionY. Set both to 0 to use your desktop size. Restart the game after changing the file.

ResolutionX and ResolutionY control the display size. RenderResolutionX and RenderResolutionY set the game's internal render size. Leave the render values at 0 unless you specifically want to override the game's choice. Always set width and height together.

Set FullscreenPauseMenu=true in SH3Enhanced.ini to expand the pause menu to widescreen. This setting is enabled by default.

FMVWidescreenMode=0 keeps the original 4:3 framing. Set it to 1 to crop the video to fill a widescreen display, or 2 when using 16:9 video sources.

The project includes an Options menu freeze fix. Check SH3Enhanced.log beside sh3.exe for an Options warning; if the fix still doesn't work, attach the log to a GitHub issue.

60 FPS is the default mode. You can also select 30 FPS or unlocked timing in the Configuration Tool or SH3Enhanced.ini.

Open an issue on GitHub. Include what happened, what you expected, your game executable version, and SH3Enhanced.log if available.
