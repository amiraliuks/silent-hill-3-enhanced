# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/amiraliuks/silent-hill-3-enhanced/security).

Include the affected release or component, steps to reproduce the issue, its potential impact, and a proof of concept if available. Please avoid posting vulnerability details in a public issue until they have been reviewed and a fix or disclosure plan has been agreed.

This is a personal project maintained by one person, so response times may vary. There is no guaranteed response or fix timeline.

For ordinary bugs, crashes, compatibility problems, and feature requests, use [GitHub Issues](https://github.com/amiraliuks/silent-hill-3-enhanced/issues).
